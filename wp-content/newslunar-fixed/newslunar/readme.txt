== Description ==

NewsLunar is a modern, responsive, SEO-friendly WordPress magazine and news theme for news portals, online magazines, newspapers, blogs, editorial websites, and content publishers. Perfect for breaking news, latest news, trending news, technology, business, sports, entertainment, lifestyle, politics, health, travel, fashion, finance, education, and multi-category blogs. Features a clean, fast, mobile-friendly, customizable, and professional magazine layout with featured posts, news blocks, category sections, post grids, widgets, sidebars, social media integration, and modern typography.

== Installation ==

1. In your admin panel, go to Appearance > Themes and click the Add New button.
2. Click Upload Theme and Choose File, then select the theme's .zip file. Click Install Now.
3. Click Activate to use your new theme right away.
